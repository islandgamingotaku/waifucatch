## ✨ C'est quoi ?

**WaifuCatch** transforme votre chat Twitch en un véritable jeu de collection. Des waifus apparaissent sur le stream, vos viewers les attrapent avec `!catch`, montent leur collection, font évoluer leurs cartes, s'affrontent et s'échangent des cartes — le tout sans quitter le chat. Vous gérez tout depuis un dashboard simple, avec des overlays prêts à ajouter dans OBS.

## 🎮 Fonctionnalités

- 🎴 **Capture dans le chat** — les waifus apparaissent sur le stream, les viewers tapent `!catch`
- 🌈 **7 raretés** (Commune → Céleste) avec taux d'apparition réglables
- ✦ **Évolution** — consommez des doublons + des points pour booster une carte (aura ✦)
- ⚔️ **Combats stratégiques** sur le Dex — équipe de 1 Chef + 3 Sbires, **éléments**, **classes** et **attaques**
- 🌍 **Combat mystère** — affrontez un joueur au hasard dans le monde
- 🔄 **Échanges** entre joueurs (chat + échange mystère sur le Dex)
- 🏆 **Classement global** cross-stream, équitable
- 🔥 **Boss raids** & **événements** déclenchables à la demande (heure dorée, pluie de points…)
- 🛒 **Boutique** de boosts et d'objets avec les points gagnés
- 🖥️ **Overlays OBS** modulaires (spawn, captures, combat, boss, dex, logs)
- 🌐 **8 langues** (FR, EN, ES, PT, DE, IT, JA, KO)

## ⬇️ Installation

1. **[Télécharger WaifuCatch](https://waifucatch.islandgamingotaku.re/#telecharger)** (portable, Windows 64-bit)
2. Lancez l'application, connectez votre **chaîne Twitch**
3. Ajoutez les **overlays** voulus dans OBS (sources navigateur)
4. C'est parti — vos viewers peuvent jouer ! 🎉

> ⚠️ Windows peut afficher un avertissement « éditeur inconnu » (l'app est récente) : cliquez sur **Informations complémentaires** → **Exécuter quand même**. C'est sans danger.

## 💬 Commandes du chat (extrait)

| Commande | Effet |
|----------|-------|
| `!catch` | Attraper la waifu visible |
| `!collection` | Voir sa collection |
| `!evolve <waifu>` | Faire évoluer (3 exemplaires + points) |
| `!duel @pseudo` | Défier un viewer en combat |
| `!trade @pseudo <waifu>` | Proposer un échange |
| `!shop` · `!buy` · `!use` | Boutique & objets |
| `!daily` · `!top` · `!dex` | Récompense, classement, son Dex |

*(Liste complète sur le [site](https://waifucatch.islandgamingotaku.re/#commandes) ou via `!help` dans le chat.)*
